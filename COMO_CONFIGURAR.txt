PESOS E MEDIDAS — VERSÃO SUPABASE

Arquivos:
- index.html = loja pública
- admin.html = painel do dono
- config.js = conexão Supabase
- admin-policies.sql = libera alterações para usuários autenticados

IMPORTANTE:
1. A chave em config.js é a Publishable Key. Não coloque Secret Key no site.
2. No Supabase, crie um usuário de autenticação para o dono (Authentication > Users).
3. Rode admin-policies.sql no SQL Editor.
4. No GitHub/Render, envie os 4 arquivos na mesma pasta.
5. Painel: /admin.html
6. A loja compra pelo WhatsApp; não há checkout/pagamento integrado.
